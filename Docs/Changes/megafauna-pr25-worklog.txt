OBJETIVO DESTE ARQUIVO
----------------------

Este é o inventário de conteúdo da expansão de megafaunas incluída na PR #25.
Ele serve simultaneamente como:

- registro do que foi portado ou criado;
- base para o changelog público dirigido aos jogadores;
- lista de acompanhamento para correções e expansões futuras;
- índice para indicar exatamente qual parte deve ser alterada.

Convenção de acompanhamento:

[IMPLEMENTADO] Conteúdo presente na PR #25.
[REVISAR]      Conteúdo implementado que precisa de nova avaliação.
[PLANEJADO]    Conteúdo aprovado para trabalho futuro.
[FORA DA PR]   Conteúdo deliberadamente não incluído na PR #25.

Entidades técnicas invisíveis, como projéteis auxiliares, marcadores, spawners e
telegraphs, são agrupadas dentro da mecânica ou boss correspondente.
