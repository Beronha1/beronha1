# Lavaland audio attribution policy

Every audio file in this directory must be covered by the nearest
`attributions.yml`. Imports record the original author, source URL and exact
license. `Custom` entries whose source is Pixabay are governed by the
[Pixabay Content License](https://pixabay.com/service/license-summary/).

Audio without a verifiable redistribution license must be replaced before it
is referenced by a prototype. `Finale.ogg` and `legion_spawn.ogg` were removed
from the content set for this reason.
